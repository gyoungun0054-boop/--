# NEXUS QR Check-in

이 저장소는 NEXUS Event Platform의 QR 체크인 담당 기능을 위한 독립형 데모입니다.

## 실행 방법
1. `index.html` 파일을 브라우저에서 엽니다.
2. QR 리더기로 입력창에 참가자 ID를 전송하거나 ID를 직접 입력합니다.
3. **입장 확인**을 눌러 참가자 확인 및 입장 처리를 테스트합니다.

## 데모 참가자
- `NEXUS-1001`
- `NEXUS-1002`
- `NEXUS-1003`

## 포함 기능
- 등록된 참가자 ID 확인
- 미등록 참가자 오류 처리
- 중복 입장 방지
- 입장 성공/실패 메시지
- 입장 시각 기록 및 참가자 목록 표시
- 브라우저 로컬 저장소에 데모 상태 저장
- 입장 현황 CSV 내보내기

## 범위 및 다음 단계
현재는 서버/API와 연결되지 않은 프런트엔드 데모이며, 카메라 QR 스캔은 아직 포함하지 않습니다. 실제 행사에 사용하기 전에는 팀 프로젝트의 프레임워크/컴포넌트 구조에 맞춰 이 기능을 통합하고, 서버에서 참가자 유효성 및 중복 입장을 원자적으로 검증해야 합니다. 브라우저 로컬 저장소는 여러 기기 간에 공유되지 않으므로 실제 입장 기록의 기준 데이터로 사용하면 안 됩니다.
